- 使用者需求（原話翻成條列）：
  1. 記帳頁的計算機模組只留「顯示金額」的欄位
  2. 點金額才另外彈出計算機子頁面
  3. 子頁面不要滑動、背景也不要滑動
  4. 移除上方「快捷記錄的金額欄」（常用金額那排）
  5. 有問題要問（我用 AskUserQuestion 問了三題，答案：**置中卡片彈窗**、
     **金額＋鍵盤＋右上「完成」**、**快捷金額完全移除**）
- 做法：
  - 新元件 `src/components/CalcSheet.vue`：置中卡片彈窗，金額狀態仍由 HomeView 持有
    （只傳 `calc`／`symbol`／`curCode` 進去、把按鍵 `press` 事件發回去），
    所以關掉再開、點背景關掉，輸入內容都不會不見
  - HomeView：`<Keypad>` 拿掉、`quickAmounts`／`setAmount` 刪掉、
    `.amount` 從 div 改成 `<button class="amount">`（左邊計算機圖示＋「點擊輸入金額／點擊修改」提示，
    右邊金額；還沒輸入時 0 壓淡）
  - **鎖背景捲動**：捲動容器是 `documentElement`（`html,body{height:100%}`，沒有內層 scroll 容器），
    所以在 `<html>` 上掛 `is-locked`，全域樣式 `html.is-locked, html.is-locked body { overflow: hidden }`
    （加在 `src/style.css`，scoped 樣式蓋不到 body）
  - **子頁面不滑動**：卡片 `max-height: calc(100dvh - 32px)` + `overflow: hidden`，
    按鍵高度 `:deep(.key) { height: clamp(42px, 8vh, 54px) }`——矮螢幕是按鍵縮小而不是長出捲軸
  - 實體鍵盤：計算機開著時 **Enter 只關計算機**（不送出記錄）、**Esc 只關計算機**（不清金額）
