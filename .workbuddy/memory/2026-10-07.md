## 記帳頁：計算機改成「點金額 → 彈出子頁面」（commit `a3eadd5`）

- 使用者需求（原話翻成條列）：
  1. 記帳頁的計算機模組只留「顯示金額」的欄位
  2. 點金額才另外彈出計算機子頁面
  3. 子頁面不要滑動、背景也不要滑動
  4. 移除上方「快捷記錄的金額欄」（常用金額那排）
  5. 有問題要問（我用 AskUserQuestion 問了三題，答案：**置中卡片彈窗**、
     **金額＋鍵盤＋右上「完成」**、**快捷金額完全移除**）
- 做法：
  - 新元件 `src/components/CalcSheet.vue`：置中卡片彈窗，金額狀態仍由 HomeView 持有
    （只傳 `calc`／`symbol`／`curCode` 進去、把按鍵 `press` 事件發回去），
    所以關掉再開、點背景關掉，輸入內容都不會不見
  - HomeView：`<Keypad>` 拿掉、`quickAmounts`／`setAmount` 刪掉、
    `.amount` 從 div 改成 `<button class="amount">`（左邊計算機圖示＋「點擊輸入金額／點擊修改」提示，
    右邊金額；還沒輸入時 0 壓淡）
  - **鎖背景捲動**：捲動容器是 `documentElement`（`html,body{height:100%}`，沒有內層 scroll 容器），
    所以在 `<html>` 上掛 `is-locked`，全域樣式 `html.is-locked, html.is-locked body { overflow: hidden }`
    （加在 `src/style.css`，scoped 樣式蓋不到 body）
  - **子頁面不滑動**：卡片 `max-height: calc(100dvh - 32px)` + `overflow: hidden`，
    按鍵高度 `:deep(.key) { height: clamp(42px, 8vh, 54px) }`——矮螢幕是按鍵縮小而不是長出捲軸
  - 實體鍵盤：計算機開著時 **Enter 只關計算機**（不送出記錄）、**Esc 只關計算機**（不清金額）
- 踩到的坑：
  - 編輯 HomeView 樣式時，把 `.pad__keypad {...}` 連著下一行的 `.pad__meta {` 一起換掉，
    留下沒有 selector 的裸屬性 → **build 在 vite-plugin-pwa 的 style hook 爆
    「Unexpected }」**，錯誤訊息指到的是編譯後 CSS 的行號（194:1／477:1），
    要回 SFC 的 `<style>` 找未配對大括號
  - `.smoke/v70.mjs` 自己寫錯兩次（不是程式錯）：`+` 鍵要先用 Keypad 左下角的
    計算機鍵（`.key--tool`）展開才存在；算式顯示運算子前後有空白（`123 + 7` 不是 `123+7`）

## 記帳頁：分類的「更多」改成彈出頁面（commit `b9911b6`）

- 使用者需求：主頁平時只顯示「常用分類」按鈕；分類的下拉／展開改成彈出頁面
- 用 AskUserQuestion 確認三題，答案：**標籤列＋子分類列**（跟原本展開後一致）、
  **點分類只選中，要按「完成」才關**、**彈窗內可捲但背景鎖住**
- 做法：
  - 新元件 `src/components/CategorySheet.vue`：置中卡片，內容直接沿用
    `CategoryPicker`（**不帶 collapsed**），所以長相跟原本展開後一模一樣，不用重寫
  - `CategoryPicker` 加 `moreExternal` prop＋`more` 事件：「更多」鈕改成發事件；
    **預設 false，其他使用處（不加這個 prop 的）行為完全不變**
  - HomeView：`<CategoryPicker collapsed more-external @more="catSheetOpen = true" />`
  - 彈窗內容 `overflow-y: auto` + `overscroll-behavior: contain`（可捲、捲到底不帶動背景），
    背景照樣用 `is-locked` 鎖住 → 跟計算機（整個不捲）不同，這是使用者指定的差別
- **捲動鎖抽成 `src/composables/useScrollLock.ts`**（`useScrollLock(toRef(props,'open'))`），
  CalcSheet 改用它；之後再有彈窗直接用這個
- 測試：`.smoke/v71.mjs` **31 passed / 0 failed**；v70 計算機回歸 **40 passed / 0 failed**
  - 踩到一次假失敗：斷言主頁 chips 時選取器 `.catbox .cat .cat__name` 會把
    **子分類列（.subs 裡的 .cats--sub）也算進去**——選中大類後主頁本來就會展開該層子分類，
    這是既有行為（memory 有記）。要只數第一列要用 `.catbox .picker > .cats .cat__name`
- ⚠ **遠端處理**：這輪做之前使用者先說「不需要 UPLOAD PAGE 和 MAIN，本地 GIT 就可以」，
  但我在他說之前已把**計算機那輪**推上去了（main a3eadd5＋gh-pages），問過之後使用者選
  **保持現狀**（線上就是計算機改版後的介面）；分類這輪**只 commit 本機（b9911b6），沒推**
