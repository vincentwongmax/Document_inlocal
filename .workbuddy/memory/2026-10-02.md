# 2026-10-02

## 個人記帳 PWA（工作區根目錄）

以 Vue 3 + Vite + TypeScript + Pinia 開發的個人記帳網頁應用，共 10 個 git commit，對應使用者列出的 17 項步驟。

### 已確認的需求決策（使用者拍板）
- OCR：Tesseract.js 離線辨識，結果僅預填、由人工確認
- 幣別：多幣別並存，主幣別預設 MOP（可改）；每筆記錄快照「當時匯率」，改匯率不影響既有記錄
- 支援「旅行模式」：設定目前記帳幣別，輸入後自動換算主幣
- 匯率：每筆可單獨覆寫，線上更新用 open.er-api.com（免金鑰），失敗沿用舊值
- 一張圖 = 一筆記錄
- 匯入一律「合併」，以記錄 id 與圖片 MD5 去重
- 匯出：單一 JSON 含圖片 base64
- 介面：繁體中文、米白紙感簡約風、單一墨綠強調色

### 架構重點
- 記錄 metadata 存 localStorage（約 5MB 上限），圖片實體存 IndexedDB（db: mop-ledger-images / store: blobs）
- OCR 語言包（tessdata_fast 的 eng/chi_sim/chi_tra，共 5.3MB）與 tesseract wasm 核心放 public/，由 Service Worker 預快取（整包約 19MB）
- scripts/fetch-tessdata.mjs 下載語言包＋複製 wasm 核心；scripts/gen-icons.mjs 產生 PWA 圖示（純 Node PNG 編碼器）
- Chart.js 只註冊需要的元件，獨立分包

### 此環境的坑（重要）
- `npm install` 的 esbuild postinstall 會 EBUSY → 用 `--ignore-scripts` 安裝，再補裝 `@esbuild/win32-x64`
- Node 的 rmSync 在此環境會被導向資源回收桶（safe-delete shim），大型 wasm／語言包刪除會失敗 → 清 dist 要用 `cmd /c rmdir /s /q`（scripts/clean.mjs）
- 無頭瀏覽器測試：puppeteer-core + 既有 Chrome（C:\Program Files\Google\Chrome\Application\chrome.exe），放 .smoke/（已 gitignore）；下載行為會被擋，改在頁面內直接產生檔案再 uploadFile

### 驗證
- 用 puppeteer 實測通過：記帳送出、localStorage 重新整理後保留、統計頁 3 張圖表、RWD 三種視角無水平溢出、離線 OCR（合成收據，信心度 92%，正確選出合計 MOP$128.00）、同圖重複上傳被 MD5 去重、重置後歸零、匯入後與匯出前 JSON 完全一致
- 曾發現並修正：日期／時間被解析成金額（2026→MOP$2,026.00）、手機版 datetime-local 撐破版面
