# 2026-10-22 — 0.1.76（數量模式收支恢復＋小數位數＋頁尾／側欄去貨幣）

## 需求（使用者原話，4 項）
1. 電腦版「本月結餘」數量模式不顯示貨幣
2. 數量模式所有頁面加回支出／收入（銷貨和庫存是一正一負）
3. 設定頁新增小數位數（0~4，預設 2，每錢包獨立，只改顯示不改資料，全頁面全模式生效）
4. 設定頁數量模式不顯示「主幣別 澳門幣 · 1 MOP ≈ MOP$1.00」

## 實作要點
- **小數位數 = module 級**：`currency.ts` 新增 `moneyDecimals`＋`setMoneyDecimals()`，
  `fmtMoney/fmtNum/fmtCompact` 預設讀它（fmtCompact 的 K/M 小數還 `Math.min(d, moneyDecimals)`）。
  settings store 用 `watch(() => state.value.moneyDecimals, sync, { immediate: true })` 同步
  （import 時要 `as syncMoneyDecimals`——store 裡自己的 setter 同名會遮蔽）。
  ⚠ 這個做法靠「RouterView :key=route.path 重掛元件」讓換頁重跑模板，實測 OK。
- Settings 加 `moneyDecimals`（types/defaults/merge 的 `normMoneyDecimals` 夾 0..4）；
  設定頁新區「顯示格式」（兩種模式都顯示，放在 WalletSection 後面）。
- **收支恢復**：把 0.1.75 的 `v-if="!settings.quantityMode"` 一一撤回（HomeView 區塊1、
  RecordSheet 類型 seg＋±、RecordRow ±、RecordList 分組 ±、RecordsView 總覽三格＋篩選＋catgrp、
  StatsView 三卡＋甜甜圈＋typedRows＋topRows＋dailyTitle＋exclsum、ImportModal COLS 加收支欄（6 欄
  grid 432px）、QuickAmountSheet 類型、HomeDefaultSheet 預設值、quickParse 的 `!quantityMode &&` 守衛）。
  幣別相關的 quantityMode 條件全部保留。
- ⚠ 數量模式分類不分收支（qCategories 全 'expense'）→ quickParse 一律用 'expense' 解分類；
  ImportModal applyEdit 的「分類與收支不符」檢查在數量模式跳過（不然收入列全被擋）。
- ReviewSheet 數量模式加 `.rtype` 支出／收入切換（金錢模式的批次上傳本來就沒有類型選擇，沒動）。
- App.vue 側欄 `fmtMoney(balance, settings.quantityMode ? '' : base)`。
- SettingsView 頁尾 `主幣別…` 整段包 `v-if="!settings.quantityMode"`。
