## 教訓
- ⚠⚠ **`<script setup>` 模板裡對 const computed 賦值不會觸發 setter** → 一律寫明確函式。
- ⚠⚠ MoreFilterMenu 的下拉**點選項不會自己關閉**（本來就是多選）→ 測試第二次操作前要先判斷
  `.mf__pop` 是否已開，否則「點 trigger」其實是在關閉。
- ⚠ 記錄頁預設區間是「今天」→ 測試種子用今天之外的日期會全部被過濾掉（畫面空白）。
- ⚠ `git ls-files` 在 core.quotePath 下會把中文檔名輸出成 `\"\\345\\225…\"`（含真的引號與反斜線）→
  `[ -f "$p" ]` 會判 false → **中文檔名會被靜默漏掉**！
  解法：`git -c core.quotePath=false ls-files`（本輪因此多同步了 `啟動專案.bat`）。
- ⚠ Git Bash 背景 `&` 啟的 preview 會被回收 → 用 Bash 工具的 `run_in_background=true`。
- ⚠ 使用者範例 `435D16H26M` 的小時數與數學不符（實際 13H）→ 程式照數學算，單驗註明差異。
