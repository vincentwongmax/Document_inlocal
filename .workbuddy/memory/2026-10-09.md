## 幫你選擇了什麼（0.1.39 決策全記錄）

   - 每趟**各自**一個顏色；之後的旅行選別的色**不會**影響以前旅行的標籤
     （歷史旅行照樣保留自己的色）。原話「是要影響到上一個旅行」依上下文
     （前句「每次旅行的顏色都不一樣」）解讀為「**不**會影響」，照此實作——
     v114 用「藍 activeTrip＋玫紅歷史旅行」兩筆記錄並列驗證，各顯各色。
   - 色板＝**8 個預設色**（`lib/color.ts` `TRIP_COLORS`：琥珀/磚紅/墨綠/藍/紫/青/玫紅/石板灰）。
     **不用**原生 `<input type=color>`（iOS 開系統面板、任意色在紙感背景對比不可控）。
     第一個琥珀＝預設；**舊資料沒有 color → 顯示一律回退琥珀**（升級前後畫面一致）。
   - **旅行中也可改色**：進行中點色板＝即時 `updateActiveTrip({color})` 寫回 store；
     還沒開始＝改草稿，「開始旅行」一起存。
   - **「旅行模式頁面的顏色跟著變」範圍拍板**＝TravelSheet 子頁面（狀態卡/「旅行中」
     標籤/模式開關的琥珀全部換 `--trip-c` 系 CSS 變數，根元素 inline 掛
     `--trip-c`/`--trip-c-soft`/`--trip-c-line`）＋記帳頁「旅行模式中」標籤。
     設定頁旅行 cell 與 TripHistorySheet **維持琥珀**（是「設定/歷史」介面，
     跟主題走、不跟某一趟旅行）。
   - **「結束時恢復」零程式碼**：色存旅行本體，activeTrip 清掉後變數自然回琥珀 fallback。
2. **記帳頁標籤**：`.page-head` 右側膠囊（CategoryIcon luggage 13px＋「旅行模式中」），
   `align-self: center`（page-head 是 baseline 對齊不修正會沉底）；顏色 inline 綁旅行色；
   沒旅行時整顆不渲染。
3. **需求 1 照字面辦**：旅行中**不管有沒有設貨幣**，提示都是同一句「由旅行貨幣決定」
   （原 v-else-if「這趟沒有設旅行貨幣」防呆分支一併移除——使用者明說移除）。
4. **「旅」右移**：DOM 把 `.ttrip` 搬到 `.row__cat` 後面；**is-stacked 不受影響**
