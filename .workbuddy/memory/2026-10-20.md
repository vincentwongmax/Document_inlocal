- `inline-block` + font-size 0.62em → 溢出 2px

### 實作
- 需求 1：**程式碼 0.1.73 就已滿足**（`RecordSheet` 的 `v-if="images.length && hasEditable"`，
  記錄來的圖 `isLocked` → 等級鈕不渲染；明細頁新上傳的圖未鎖定 → 出現）。這次補 v148 實測釘死兩種狀態。

  ＋ `fitScaleNow()` 等比縮字級

### ⚠ 需求 3 除錯：三個坑（每個都花掉一輪 build+測試）
1. **flex item `min-width:auto`**：`.calcdisp__num` 是 `.calcdisp__main`（flex）的 item，
   不肯被壓縮 → 長字串撐破面板。桌機沒事只是因為字體窄 + 視窗寬。
2. **`scrollWidth` 量不到自然寬度**：`.calcdisp__num` 有 `max-width:100%`，
   `scrollWidth` 被夾在容器寬內 → `natural/avail` 恆為 ≈1 → 永遠不縮小。
   `getBoundingClientRect()` 更糟（量到已壓縮後的寬度）。
   → 只能用 `Range.selectNodeContents()` 量文字實際排版寬度。
3. **「量測自我消除」**：第二次量測時字級已經縮過 → 量到縮後寬度 → `s<1` → 判定「放得下」
   → 還原成 24px → 下次又溢出。在 24px 與縮排之間無限跳動，看起來就是「沒生效」。
   → **量之前必須先 `num.style.fontSize = base` 再量**（讀 rect 本身會強制排版）。
4. ⚠⚠ **production build 下 template 的 `:style` 綁定沒有被 Vue 寫進 DOM**
   （`num.getAttribute('style')` 一直是 null、MutationObserver 完全沒動）→
   等距縮排等於完全沒作用。改成在 `fitScaleNow()` 裡直接寫 `num.style.fontSize`
   （此元素本來就沒有任何 Vue 樣式綁定會碰 font-size，不會被 patch 蓋掉）。
