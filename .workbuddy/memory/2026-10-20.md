### 教訓
- Vue template 的 inline handler **不能寫多行語句**（`@close="a = null\nb = null"` 會 build 爆）→ 抽成函式
- 量字體寬度別用 `style.font = getComputedStyle().font`（shorthand 會解析掉字級）→ 逐項指定 fontFamily/fontSize
- `settings.$patch` 是巢狀的 → 要 `$patch((s) => { s.state.xxx = v })`；讀設定是 `settings.state.xxx` 不是 `settings.xxx`
