# 2026-10-27

## 0.1.83：應用鎖（Face ID／PIN 碼）

使用者需求（原話）：
「在設定頁中加入apple 的FACEID 鎖屏代碼，用戶在PWA (IPHONE) 的模式下，打開PWA 應用時，
要求用戶輸入FACEID 才能打開應用，另外加入PIN 碼模式，用戶可以在FACEID 和PIN 模式2選1，
桌面版和其他用戶就只可以用PIN 碼模式」。

### 先問過使用者的 4 個決定
1. PIN 位數 → **4–8 位自選**
2. 鎖定時機 → **切回前台超過 1 分鐘**才重鎖（重新打開 App 一定鎖）
3. Face ID 模式 → **保留 PIN 備用**
4. 忘記 PIN → **用恢復碼**（不是一鍵重置）

### 實作
- `src/lib/appLock.ts`（核心）
  - localStorage `mop-ledger.lock.v1`：`{enabled,mode,pinHash,pinSalt,pinLen,credId,recoveryHash,recoverySalt,updatedAt}`
  - PIN：PBKDF2-SHA256、12 萬次迭代、16 bytes 隨機鹽 → 只存 base64 雜湊
  - 恢復碼：10 碼（去掉 I/O/0/1），顯示成 `ABCDE-FGHJK`；只存雜湊；只顯示一次
  - Face ID：`navigator.credentials.create/get`，`authenticatorAttachment:'platform'`、
    `userVerification:'required'`、`rp.id=location.hostname`；只存 credential rawId（base64）
  - `isIOSPwa = isIOSDevice() && isStandalone` ＋ `isUserVerifyingPlatformAuthenticatorAvailable()`
    → `faceIdAvailable`（桌面/Android 只有 PIN）
  - 上鎖狀態只放**記憶體**（`unlocked`）：重新載入＝重新上鎖
  - `visibilitychange`：hidden 記時間，visible 時超過 `RELOCK_MS=60000` 才 `unlocked=false`
- `src/components/AppLock.vue`（鎖屏）
  - fixed inset:0、z-index 2000、不透明 `var(--bg)` → 蓋住整個 App
  - Face ID 模式：大按鈕＋「改用 PIN 碼」＋「忘記 PIN」；**不在載入時自動觸發**
    （WebAuthn 要手勢），另加 90 秒安全網避免按鈕卡在「驗證中…」
  - PIN 模式：自製數字鍵盤，打到 `pinLen` 位自動送出；錯→震動＋清空；⌫
  - 恢復碼：頁內輸入（不用 SweetAlert，因為 z-index 1060 < 2000 會被鎖屏蓋住）
- `src/components/LockSettings.vue`（設定頁區塊）
  - 啟用：兩次 PIN → 顯示一次性恢復碼 →（iPhone PWA）問要不要同時開 Face ID
  - 變更 PIN／開關 Face ID／重產恢復碼／關閉鎖 → **都先驗目前 PIN**
- `src/lib/alerts.ts`：新增 `askPinDialog`／`askRecoveryDialog`／`showRecoveryCodeDialog`
- `src/App.vue`：setup 同步阶段 `initAppLock()`（避免先閃內容）＋ `<AppLock v-if="isLocked" />`
- `src/views/SettingsView.vue`：在「App 圖示」與「離線與版本」之間加「應用鎖」section

### 教訓
- Face ID ≠ 相機人臉辨識；Web 上只能用 WebAuthn（系統 Face ID），且**必須使用者手勢**。
- 鎖屏不要用 SweetAlert（z-index 1060 會被 2000 的鎖屏蓋住）→ 恢復碼改頁內輸入。
- 設定頁新增 section 不影響舊測試（都按文字找），但**不要新增 `<select>`**。
