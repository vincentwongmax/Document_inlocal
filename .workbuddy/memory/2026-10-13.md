## 0.1.55（修 PWA 餵食「轉圈一直轉、沒有 11~20」）

使用者回報：PWA 記錄頁往下滑，loading 一直轉但沒有下一批。

- **根因**：IO `rootMargin: 400px` vs `pump()` 停止條件 `top > innerHeight`（不算提前量）→ 兩個判定不一致 → 死區。哨兵停在「視窗下方 0~400px」時：IO 判定相交叫 pump → pump 直接 return；而 **IO 只在相交狀態改變時回呼**，哨兵之後一直在視窗內（gap −186）→ 永遠不再叫 → 卡死
- ⚠⚠ **為什麼 0.1.54 測試沒抓到**：v129 用 `scrollTo(0, scrollHeight)` 一次跳到底 → 哨兵直接落進視窗內（top < innerHeight）→ 不 return → 一路載到 60。**一次跳到底剛好跳過 400px 死區**；真機手指「慢慢滑」才會走進去 → 以後測無限滾動**一律用 scrollBy 一小段一小段滑**
- **修法**：共用常數 `FEED_SLACK = 200`（IO rootMargin 與 pump 停止條件 `top > innerHeight + FEED_SLACK` 同一個）；pump 加 `pumping` 鎖；加 window scroll 備援（passive + rAF 節流）防真機 IO 不穩
- 實測：初始仍 10 筆（哨兵在視窗下方 490px）；慢慢滑 10→20→30→40→50→60；載完轉圈收掉
- 測試：新增 v130（18/18）全程 scrollBy 模擬手指，含**死區專測**（把哨兵精確停在視窗下方約 100px）；v129 ②補「慢慢滑」斷言並把載完那段改成分段滑
- 回歸 ALL 加 v130 → v70~v130（54 支）
