### 實作
- `RecordSheet.vue`：刪除鈕改走 `onDelete()` → `confirmDialog({title:'刪除這筆記錄？', message 說明可復原, confirmText:'刪除', danger:true})`，
  只有 `'confirm'` 才 `emit('remove')`；移除與復原吐司仍由父層 `removeEditing` 負責（行為不變）
- `RecordsView.vue`：`todoFilter` ref（off/has/done/pending）＋`TODO_CYCLE` 循環；`rows` computed 在 typeFilter 後多疊一層
  （has＝todos.length>0；done＝length>0 且全 done；pending＝有 !done）；emptyText 三句；兩個 reset watch（byCat/page、feedCount/pump）都加 todoFilter
- 篩選語意：has/done 都要求 length>0；pending 只要有一個未完成（不管其他完成與否）
- 待辦鈕在「最近」與「依新增時間」之間，class `bycat`，`is-on` 當非 off；四檔 icon 兩兩不同（項目符號／勾選清單／打勾方框／空方框）
- 窄屏「依新增時間」→「依實**時**」（⚠ 繁體「時」不是简体「时」——v85/v94/v109 第一次改測試時我打錯字全紅，來源碼一直是對的）
- 排版：`.grp__row--view { flex-wrap: nowrap }`；≤519px gap 6px＋.bycat padding 0 9px
- ⚠⚠ **320px 真 bug**：四顆內容實測 312px > 320px 時列寬 254px → nowrap 整排溢出卡片（v94 overflow=1）
  → 加 `@media (max-width: 374px)` 緊湊斷點（gap 4px／.bycat padding 0 4px＋gap 4px＋font 12px／icon 14px）→ 內容降約 242px，320/340/360 全過
