## v68 修掉「所屬分類」標籤被壓成兩行（懸掛縮排）
- 症狀（使用者回報）：分類彈窗裡「所屬分類」的「類」跑到第二行、不跟「分」對齊，
  看起來像懸掛縮排。先前有跟使用者說過這是舊問題，這次他回「請修正,處理」
- **先量再改**：寫了臨時探測腳本 dump 每一列的幾何（Range 取實際文字 rect），量到：
  - 內容寬只有 **320px**（`.box` `max-width: 356` − `padding: 18` × 2）
  - 「所屬分類」被壓成 **3 個字（38px）+ 1 個字（13px）** 兩行
  - 提示拿到 261px 但需要 **264px** → 尾巴「類」被擠到第二行
- 根因：`.lb > span` 是 `display: flex`。標籤是**匿名彈性項目**（裸文字節點），
  它和 `.lb__hint` 都預設 `flex-shrink: 1` + `min-width: auto`；
  中文可以在任何字之間斷行，所以標籤的 min-content 只有 1 個字 → **可以被壓到剩 3 個字**
- 修法（CSS 就好，不用動模板）：
  ```css
  .lb > span {
    display: grid;                                   /* 原本 flex */
    grid-template-columns: max-content minmax(0, 1fr);
    align-items: baseline;
    gap: 7px;
  }
  .lb__hint { text-wrap: pretty; }                   /* 避免尾行只剩一個字 */
  ```
  - 第 1 欄 `max-content` → 標籤拿自己剛好的寬度，**永遠不會被壓縮或斷行**
  - 第 2 欄 `minmax(0, 1fr)` → 提示吃掉剩餘寬度，在**自己的欄位內**換行（各行左緣相同）
- 順手把最長的那句提示收斂成跟其他提示一致的長度（原本 24 字、其他都 13–14 字）：
  「選一個就變成它的子分類；選「無」則是最上層的大類」→「選了就變成它的子分類；選「無」是最上層大類」
  （21 字 ≈ 231px < 261px，收成 1 行）
- 測試 v68（138 assertions 全過）驗的是**版面不變式**而不是某句文案：
  - A 每個標籤都只佔 1 行；B 標籤左緣 = 容器內容左緣（記得 `getBoundingClientRect` 是 border box，
    要再加 `borderLeftWidth`，否則永遠差那 1px）；C 標籤右緣 <= 提示左緣（兩欄不重疊）；
    D 提示不溢出內容右緣；E 提示每個換行段左緣相同
  - 跑四個寬度：480（3 個情境）→ 360（提示真的被迫換行）→ 320（極窄）→ 回到 480（還原）
  - 窄視窗那兩段是關鍵：**提示一定會折**，要驗的是「折了之後仍然沒有懸掛縮排」

## 環境：C 槽爆滿（99%，剩 1.2GB）導致測試整批靜默失敗
- 症狀：同樣的回歸迴圈跑完**完全沒有輸出**，preview 服務也消失
- 原因：C: 只剩 1.2GB，Chrome 開 profile 與寫截圖都會卡住／失敗
- 解法（**不動 C: 上任何東西**）：把產出與暫存導到 E:（440GB 可用）
  - `mkdir -p /e/wb-run/.smoke /e/wb-tmp`，然後 **cd 到 `/e/wb-run` 執行測試**
    → `.smoke/xxx.png` 這種相對路徑就落在 E: 上（測試檔本身用絕對路徑照樣跑得到）
  - 再設 `TEMP='E:/wb-tmp' TMP='E:/wb-tmp'` → Node 的 `os.tmpdir()` 跟著到 E:，
    Chrome 的 user-data-dir 就不會塞爆 C:
- ⚠ **curl 對 localhost 會踩到 proxy**：環境有 `HTTP_PROXY/HTTPS_PROXY=http://127.0.0.1:50208`，
  `curl http://localhost:4173/` 會回 **502**（proxy 連不到），看起來像服務掛了。
  要加 `--noproxy '*'` 才是真話。另外 `vite preview` 只綁 **IPv6 `[::1]:4173`**，
  `curl http://127.0.0.1:4173/` 會失敗，要用 `localhost` 或 `[::1]`
- ⚠ preview 服務不要用 `(npm run preview &)` detached 啟動——會被連帶收掉，
  要用工具的背景執行（run_in_background）
- 一次性工具的教訓：**回歸迴圈的摘要解析要能認得專案裡三種輸出格式**
  （`N passed, M failed` / `全部通過` / `=== errors ===` + `(無)`），
  否則會把「跑過且沒問題」誤判成失敗（v47 就被誤判過）
