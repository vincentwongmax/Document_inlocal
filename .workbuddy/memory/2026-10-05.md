- 使用者：統計的頁面中，分類佔比中，(當圓形圖和長條圖在同一行時)餐飲和交通左邊的LOGO要空一間

- 修好後實測：900 / 1024 / 768 / 420px，每列 icon→名稱間距都是 9px（=grid gap），icon 不再溢出；
  420px 時圓餅圖仍是置中（margin: 0 auto，左 80 / 右 80）
- 新測試 `.smoke/v50.mjs`（68 項全過、0 console error）：四個寬度 × 支出/收入兩個分頁，
  斷言 col1=22px、icon 不溢出、gap≥8、長條仍有寬度、圓餅與列表的相對位置

## 記帳頁分類列：新增「收起」小 ICON 鈕（原本展開後收不回來）
- 使用者：記帳頁中，分類中，更多的分類按鈕(已有)，也要建立收起分類的按鈕(ICON)
- 根因（也是 bug）：`CategoryPicker.vue` 的「更多」鈕顯示條件是 `collapsed && all.length > list.length`，
  展開後 `list === all` → 條件不成立 → **按鈕直接消失，展開後永遠收不回來**
- 修正（`CategoryPicker.vue`，chips 模式）：
  - 新 computed `expandable = collapsed && favorites.length > 0 && all.length > favorites.length`
    （沒勾選常用分類時全部顯示，兩顆鈕都不出現）
  - `hiddenCount` 改用 `all.length - favorites.length`（原本用 list.length，選中分類被插隊時會差 1）
  - 「更多」（`v-if="expandable && !expanded"`，單一向下箭頭、白底）與
    「收起」（`v-if="expandable && expanded"`，**向上箭頭＋上方橫線**兩段 path、墨綠淡底 `--accent-soft`）
    刻意分成兩顆、圖示與底色都不同，不是同一顆旋轉
  - 刪掉不再使用的 `.cat-more__icon.is-up`（rotate 180）與 transition
- 影響範圍：只有 HomeView 傳 `collapsed`，ReviewSheet 的 chips（沒傳）與 RecordSheet 的 select 模式都不受影響
- v51 測試（35 項全過、0 console error）：初始只有更多、展開後收起鈕在、收回後更多鈕在、
  來回三次不卡住、展開後點非常用分類仍自動收起且選中的看得到、已選仍是粉紅、
  沒勾選常用分類時兩顆鈕都不出現
- 測試陷阱：內建**支出**分類是 9 個（收入另 4 個），別把全部 13 個當成展開後的數量

## 記錄明細：收據圖片放大頁新增「放大／縮小」ICON 鈕
- 使用者：記錄明細的頁面中，收據圖片，點擊查看圖片頁面，增加(放大(ICON)，縮小(ICON)的按鈕)
- `RecordSheet.vue`：
  - 新狀態 `zoom`（1～5，每階 ×1.4）、computed `zoomIn`/`zoomOut` 決定按鈕停用、
    `clampZoom` + `roundZoom`（連乘會出現 2.7440000000000002 這種浮點數，且最後一階會跨過上限
    1.4^4=3.84 → 5.376 變成 538%，**一定要 clamp 才會停在 500%**）
  - `closeLightbox()`：關閉時倍率歸位；`openImage()` 每次開圖也重設為 1
  - 版面改為 column flex：上層 `.lightbox__stage` 是可捲動的檢視區、下層 `.lightbox__bar` 工具列固定
    **置中用 `img { margin: auto }` 而不是 `place-items: center`** —— grid/flex 置中在內容超出容器時
    會把上半／左半裁掉且捲不到（unreachable overflow），auto margin 才不會
  - 圖片用 `transform: scale()`（不改版面、天然可做 scrollable overflow）
  - 行為調整：點黑色背景才關閉，**點圖片本身不關閉**（不然放大後整片都是圖片，沒地方點）
  - `.lightbox__x` 補 `z-index: 2` + `box-shadow`，放大後圖片會蓋到右上角，白圖上原本看不見
- UI 三件：**縮小**（放大鏡＋減號）／**倍率**（本身也是鈕，點一下回原始大小，100% 時停用）／**放大**（放大鏡＋加號）
- v52 測試（40 項全過、0 console error）：初始 100% 且縮小鈕停用、放大後 scale 與圖片實際寬度都變大、
  一路到 500% 停用上限、可水平捲動、倍率鈕重置、逐步縮小、關掉再開倍率歸位、點圖片不關／點背景關
- 測試陷阱：
  - 定位用 `aria-label` 不要用 `:nth-of-type` —— 中間那顆倍率鈕也是 `<button>`，會算進去
  - 「加號」寫在同一個 `<path>` 的 `d` 裡（`M8.3 10.6h4.6M10.6 8.3v4.6`），數 path 元素數量兩個都是 2，
    要比 `d` 內容有沒有 `v`
  - 測 Firefox/其他瀏覽器前要確認 `transform` 造成的 overflow 是否可捲（Chrome 可以）
  - 種測資：用 canvas 生 1200×800 圖，直接用原生 IndexedDB 寫 `mop-ledger-images` / `blobs`
    （這正是 idb-keyval `createStore('mop-ledger-images','blobs')` 用的名字）
