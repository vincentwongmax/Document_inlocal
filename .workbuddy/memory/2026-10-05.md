## 記錄頁搜尋功能（備註＋分類、命中黃底高亮）
- 使用者：在記錄的頁面中增加搜索的功能，只顯示搜索備注和分類，搜索的結果要高亮(黃色)該文字
- 新檔 `src/components/HighlightText.vue`：把文字切成「未命中/命中」交錯片段，命中用 `<mark class="hl">`。
  **刻意不用 RegExp**（使用者輸入 `(` `*` 不必跳脫、無 ReDoS），用 `toLowerCase().indexOf()` 迴圈切；
  多根 fragment 輸出（不外包標籤），所以 `.row__note` 的 ellipsis 仍作用在外層元素上
- `src/style.css` 新 token：`--hl: #ffe066`（黃底；配 `--text` 深字對比極高）
- `RecordRow.vue` 新 prop `highlight?: string`（預設 ''），分類名與備註都用 `<HighlightText :query="highlight">`；
  原 `defineProps<{...}>` 改成 `withDefaults`
- `RecordList.vue` 新 prop `highlight`，單純往下傳（RecordList 也用於統計頁，不傳即無作用）
- `RecordsView.vue`：
  - `q`（原字）/ `kw`（trim+toLowerCase）兩個 ref/computed；`catNameOf()` 用同一個「未分類」fallback，
    所以未分類的記錄也搜得到
  - `rows` 過濾條件變三層：日期區間 → 收支類型 → 關鍵字（AND）
  - `emptyText` computed：有關鍵字時顯示「找不到符合「xxx」的記錄」，否則原本文案
  - 搜尋框放在 `.rangebar__top` 之後（兩種模式共用）：放大鏡 SVG 絕對定位在左 12px、
    `:deep(.cf__in) { padding-left: 36px }` 讓開；右側沿用 ClearableInput 的清空鈕（40px）
  - 支出/收入/結餘與「N 筆」標籤都從 rows 算，搜尋時自動跟著縮
