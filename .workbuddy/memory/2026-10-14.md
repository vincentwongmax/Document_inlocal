## 0.1.60 PWA 離線可靠性加固（完成）

使用者原話：「請檢查，確保用戶在 PWA 模式(iphone)下，只要第一次連線後，之後永久可以離線使用，
即使超過7天，14天等等以上沒網路，都不會出現訪問不到應用程序」

### 檢查結論
- 平台事實：iOS Safari「7 天無互動清腳本儲存」規則，**主畫面 PWA 明文豁免**（WebKit ITP 文件）→ 不用改程式
- ① Google Fonts 沒進任何快取（渲染阻塞外部樣式）→ 加 runtimeCaching CacheFirst
  - ⚠⚠ workbox 坑（ debug 半天）：`<link>` 樣式表是 no-cors → opaque（status 0）；
    這個 workbox 版本 cachePut 無 cacheWillUpdate 外掛時只收 200 → 樣式表永遠不快取
    （字型檔 cors/200 所以只有字型進得去）→ 兩條路由給 `cacheableResponse:{statuses:[0,200]}`
- ② 儲存壓力驅逐 → pwa.ts 開機呼叫 `navigator.storage.persist()`（iOS 不支援＝no-op）
- ③ globPatterns 加 `webmanifest`（manifest 原本沒預快取）
- 沒問題的：version.json／匯率 API 都只手動觸發且離線有 Toast；hash 路由；IndexedDB 圖片；OCR 預快取

### 測試坑（v135）
- puppeteer 25 **沒有** setOffline → `page.emulateNetworkConditions({offline:true,download:-1,upload:-1,latency:0})`
  （鍵名是 download/upload，不是 downloadThroughput）
- 字型要**第二次 reload** 才進 SW 快取（首次載入時 SW 還沒控制頁面，字型在 HTML 解析就請求完了）
- precache 的 index.html 網址帶 `?__WB_REVISION__=` → 斷言用 includes 不用 endsWith
